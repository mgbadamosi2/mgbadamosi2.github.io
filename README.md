# Gbadamosi Lab Website (`mgbadamosi2.github.io`)

Zero-build, GitHub Pages-ready website with **Light & Dark Mode** (fluorescence-inspired dark theme + clean editorial light theme).

## Structure
- `index.html` — Home (hero, research pillars, New & Notable feed)
- `research.html` — Research program details
- `publications.html` — Searchable, topic-filterable publication list
- `people.html` — PI, lab members, and alumni
- `join.html` — Recruiting & contact info
- `reflections.html` — Faith & Gospel, favorite quotes, and personal notes
- `css/styles.css` — Theme variables and responsive layout
- `js/main.js` — Theme toggle, mobile menu, and dynamic page rendering

## Easy Content Updates (No Build Step Required)
Edit the files in `data/` and push to GitHub:
- `data/news.js` — Add/edit homepage news items
- `data/publications.js` — Add/edit papers
- `data/people.js` — Update PI bio, lab members, and alumni
- `data/reflections.js` — Add Gospel reflections, favorite quotes, and personal thoughts
